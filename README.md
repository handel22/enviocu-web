# envío.cu — páginas de descarga

Solo las páginas públicas de descarga de las apps de envío.cu (cliente y mensajero).

- Portada: `index.html`
- Cliente: `cliente/index.html`
- Mensajero: `mensajero/index.html`

Las APK se descargan desde el enlace público de Supabase que ya usan las páginas. Este repo no contiene código de las apps ni secretos.
